# Code of conduct

This project follows the [Contributor Covenant 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/).

Be civil, stay on the technical point, and assume good faith. Harassment, personal attacks and spam are removed, and repeat offenders are blocked.

Report conduct problems to the maintainer through a [private security advisory](https://github.com/w21180239/not-a-bot/security/advisories/new) (it is the one private channel the repository offers) or by opening a minimal issue asking for contact.
