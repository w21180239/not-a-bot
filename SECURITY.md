# Security policy

Report vulnerabilities privately through [GitHub security advisories](https://github.com/w21180239/not-a-bot/security/advisories/new), not in a public issue.

Relevant reports include text that makes `not-a-bot` run unintended commands, read or write files outside what the request names, or send content to a provider the configuration did not select; and prompt injection that leaks the rewrite brief's inputs to a third party.

Only the latest release is supported. Expect a first reply within a week.
