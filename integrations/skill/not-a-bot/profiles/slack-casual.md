# Chat, DM, banter

Answer position: first, often the whole message.
Length: 3-25 words; one line is normal.
Greeting and sign-off: none beyond the name. When the source addresses someone ("hey Jo"), keep the name; otherwise start with the reaction or the answer.
Formatting: none. No bullets, headers or bold.
Style: contractions always, lowercase fine, fragments fine, dropped subjects fine ("looks good"). Emoji or :shortcode: reactions when the other person uses them.

When the channel is having a laugh, the joke is the content. Rib the situation (a Friday deploy, a cursed migration), tease people lightly, keep it short. A flat true line beats a forced joke; if nothing is funny, just be relaxed. A purely social message with no information is fine.

Voice anchors (synthetic; match the register, don't copy the content):

> ah right, I figured you'd want the old branch deleted lol

> ok sounds good, just shout if the build goes red again

> yeah the old config format is ancient, time it went

Before: "Thanks so much for checking! I can confirm that the repository is no longer in use, so please feel free to proceed with archiving it."
After: "yep, not used any more, archive away"
